🧰 ABA – Bestandsaufnahme App
📱 Was ist das?
Die ABA‑App dient zur einfachen digitalen Erfassung von Baustellen‑ und Montage‑Daten.
Sie funktioniert offline, nachdem sie einmal installiert wurde.

📲 Installation auf iPhone / iPad (iOS)
1. App‑Seite öffnen
Öffne im Safari‑Browser folgende Adresse:

https://ansgarseine.github.io/ABA/ (ansgarseine.github.io in Bing)  
(Seite muss einmal online geladen werden)

2. App installieren
Unten in Safari auf das Teilen‑Symbol tippen
(Quadrat mit Pfeil nach oben)

Nach unten scrollen

„Zum Home‑Bildschirm“ auswählen

Namen bestätigen → Hinzufügen

Die App erscheint jetzt wie eine normale App auf dem Startbildschirm.

3. Offline benutzen
Nach der Installation funktioniert die App komplett offline.
Einfach öffnen und loslegen.
